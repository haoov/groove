# Groove

Groove is a desktop workspace for a platform engineer who works through agents.

One window holds your sessions. A session is one unit of work: a task, a review or an
exploration. Each session has its repos, worktrees, diff, merge request (MR), terminals
and one agent. You open sessions, watch what the agents do, approve what leaves your
machine, review the changes and land them.

## Read in this order

1. [Install](install.md) Groove on Linux or macOS.
2. Do the [first run](first-run.md): the config file, the tools, a task source.
3. Learn the [concepts](concepts.md): sessions, worktrees, notes, the agent and asks.
4. Connect [clusters](clusters.md) when your work touches Kubernetes.

When something does not work, read [Troubleshooting](troubleshooting.md). The
[Reference](reference/README.md) lists the config keys and the keymap.

This guide is for users. The contributor docs are in the
[`docs/` folder](https://github.com/haoov/groove/tree/main/docs) of the repo.

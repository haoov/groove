# File a task from this exploration

An argument, when given, is the source to file at — `notion`, `github`.

1. `get_task_template` — the headings to mirror. Empty means the source has none.
2. `create_task_from_explorer` with a one-line title and a short body.

The title names the outcome, not the investigation. Drop any heading you have
nothing real to say under.
